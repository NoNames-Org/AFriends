# AFriends — архитектура

AFriends — клиентский Fabric-мод: друзья, мессенджер со сквозным шифрованием, уведомления и API для аддонов.
Всё, что привязано к конкретному серверу (меню БП, магазин, пати, навигатор режимов bloodstone.boo),
живёт в аддонах, а не в ядре.

## Слои

```
┌──────────────────────────── аддоны (отдельные моды) ────────────────────────────┐
│ BloodDesignerAdvance (БП, магазин, пати, навигатор)   AFriendsParty …            │
└───────────────▲──────────────────────────────────────────────────────────────────┘
                │ только dev.no.name.afriends.api (+ ui-kit)
┌───────────────┴──────────────────────── AFriends ────────────────────────────────┐
│ api/        публичный контракт: AFriendsAddon, AFriendsApi, точки расширения     │
│ addon/      реестр аддонов: загрузка entrypoint "afriends", изоляция ошибок      │
│ gui/        окна: друзья, мессенджер, настройки, уведомления; ui-kit (виджеты)  │
│ core/       данные: друзья, ЛС, группы, архив, хранилища, миграция данных        │
│ net/        сеть: туннель Noise, ключи, PQXDH + Double Ratchet, статусы          │
│ compat/     слой под версию Minecraft (versions/<mc>/…)                          │
└───────────────────────────────────────────────────────────────────────────────────┘
                │ TLS + Noise NK
┌───────────────┴──────────────── nonames-cloud ───────────────────────────────────┐
│ сервер сети (Node/TS, SQLite) · портал · версии из GitHub Releases               │
└───────────────────────────────────────────────────────────────────────────────────┘
```

Правило зависимостей: аддон → `api` → ядро. Ядро ничего не знает об аддонах, кроме интерфейсов из `api`.
Ошибка в аддоне ловится реестром (`Addons.guard`), пишется в лог один раз и не роняет игру.

## API для аддонов

Точка входа в `fabric.mod.json` аддона:

```json
"entrypoints": { "afriends": ["com.example.MyAddon"] },
"depends": { "afriends": ">=2.0.0" }
```

`AFriendsAddon.register(AFriendsApi api)` вызывается один раз при запуске. `AFriendsApi.version()` —
версия контракта: новые методы добавляются, старые не ломаются в пределах мажорной версии.

| Точка расширения | Зачем |
|---|---|
| `addRailButton` | своя кнопка в панели справа от чата (+ своя панель) — так Advance добавляет «Пати» |
| `addFriendAction` | пункт в меню друга («Позвать в пати») |
| `addComposeAction` | кнопка у поля ввода в ЛС |
| `addMessageCard` | своя карточка вместо текста сообщения (приглашение в пати) |
| `addFriendStatus` | строка под ником и доступность |
| `addSettingsCategory` | своя категория в настройках AFriends |
| `addSendCheck`, `setPrivacy`, `setProfileStatus`, `addFriendRequests`, `addFriendListener` | как раньше |
| `notifications()` | показать уведомление в правом верхнем углу |
| `friends()`, `sendMessage`, `viaNetwork` | друзья и ЛС от имени игрока |
| `events()` | вход/выход с сервера, друг в сети, новое сообщение |

UI-kit (`dev.no.name.afriends.gui.widget`, `gui.render`, `gui.theme`, `compat`) открыт аддонам, чтобы их окна
выглядели как родные. Это тоже контракт, но менее строгий: может меняться между минорными версиями.

## Данные игрока

| Что | Где |
|---|---|
| настройки, ЛС, головы | `config/afriends/` |
| ключи сети (один аккаунт на компьютер) | `%APPDATA%/AFriends` · `~/Library/Application Support/AFriends` · `~/.local/share/AFriends` |

При первом запуске `DataMigration` копирует данные из старых папок `config/blooddesigner/` и `…/BloodDesigner`,
если новых ещё нет. Старые остаются резервной копией.

Строки-метки криптопротокола (`smphelper-ratchet-v1` и т. п.) — байтовые константы протокола, а не название
мода: они не меняются, иначе у всех игроков перестанут расшифровываться ключи и переписки. В коде они собраны
в `ProtocolLabels` под нейтральными именами.

## Этапы

1. **Ядро AFriends.** Переименование (id, пакет, ассеты, миграция данных), удаление SMPHelper, значок A,
   новое API, вынос БП/магазина/пати/навигатора в BloodDesignerAdvance, без категории «Меню» в настройках.
2. **Мессенджер.** «Новости от AFriends», создание группы как в TG, мини-профиль (участники, поиск
   голосовых и картинок), права и префиксы в группах, архив, метки доставлено/прочитано, форматирование,
   поиск по нику, опросы от участников, без подписи под фото, исправление статуса «в сети», настройки
   мессенджера внутри мессенджера.
3. **Уведомления, звук, версии и сервер.** Уведомления в углу, категория «Звук» (звуки AFriends, микрофон,
   ГС), «О моде» (версии, авторы, «Обновить» → no-names.com/projects/AFriends). Сервер: без SMPHelper,
   версии из GitHub Releases, сообщения от имени AFriends, ключи с правами, «где играет» для админов,
   отступы картинок на портале.

## Этап 2: мессенджер — протокол

Сервер по-прежнему не видит содержимого: он хранит только состав групп, права и префиксы участников, описание
профиля и список личных чатов с не-друзьями. Всё остальное идёт сквозным шифрованием.

### Права в группах

Права — битовая маска у каждого участника (`group_members.perms`), владелец имеет все права всегда.
Менять права и префиксы может только владелец.

| Бит | Право | Подправо |
|---|---|---|
| 1 | Отправка сообщений | выключено — нельзя ничего, включая текст |
| 2 | ↳ картинки | |
| 4 | ↳ гифки | |
| 8 | ↳ голосовые | |
| 16 | ↳ опросы | |
| 32 | Изменение названия группы | |
| 64 | Изменение описания группы | |
| 128 | Изменение аватарки группы | |
| 256 | Добавление участников | |
| 512 | Исключение участников | владельца исключить нельзя |
| 1024 | Закрепление сообщений | |

По умолчанию у участника: 1 | 2 | 4 | 8 | 16 | 256 (= 287).

- `group.perms {group, id, perms}` — только владелец; маска проверяется (`0 ≤ perms < 2048`).
- `group.prefix {group, id, prefix}` — только владелец; до 16 видимых символов, пусто — без префикса.
- `group.add` требует бит 256, `group.kick` — бит 512 (или владелец).
- `sync.groups[].members[]` получают `perms` и `prefix`.

Сервер не может проверить, что внутри сообщения, поэтому права на отправку проверяют клиенты: у отправителя
выключены кнопки, у получателя сообщение участника без права не показывается (по правам из последнего sync).

### Сквозные сообщения (новые `k`)

| `k` | Поля | Что |
|---|---|---|
| `gmeta` | `g`, `n?`, `d?`, `a?` | название / описание / аватарка группы (`a` — картинка как `img`); принимается, только если у отправителя есть право на это поле |
| `rcpt` | `to` (id сообщений), `s` (`d` доставлено, `r` прочитано) | отметки; «прочитано» не шлётся, если игрок выключил это в настройках мессенджера |

Старые клиенты незнакомые `k` пропускают. `gname` остаётся для совместимости.

### Профиль и личные чаты с не-друзьями

- `profile.about {text}` — описание профиля до 140 символов; видно друзьям, участникам общих групп и тем,
  с кем есть личный чат. Хранится на сервере открытым текстом (как ник).
- `chat.open {name}` — начать личный чат с игроком сети по нику. Сервер проверяет, что игрок разрешает писать
  всем (`settings.dm`: `all` по умолчанию или `friends`) и не заблокировал тебя; возвращает карточку ключей.
  После этого `canReach` разрешает переписку в обе стороны. Не чаще 20 новых чатов в час.
- `chat.block {id, on}` — заблокировать / разблокировать: личный чат закрывается, писать нельзя.
- `sync.chats[]` — карточки собеседников личных чатов (чтобы расшифровывать их сообщения).

### Только на клиенте

- Архив чатов — у себя в `messages.json`; новое сообщение возвращает чат из архива, если он не заглушён.
- Форматирование: `# заголовок`, `## подзаголовок`, `**жирный**`, `*курсив*`, `__подчёркнутый__`,
  `~~зачёркнутый~~`, `` `код` ``, `> цитата`. Разметка — часть текста, старые версии покажут её как есть.
- Настройки мессенджера — кнопка внизу слева в мессенджере; из общих настроек всё про сообщения убрано.
