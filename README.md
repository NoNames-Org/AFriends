# BloodDesigner

Клиентский мод для Fabric: друзья, пати, мессенджер и навигатор режимов для сервера Bloodstone.

## Возможности

- **Панель в чате** — справа ряд кнопок: друзья, пати, сообщения и настройки.
- **Друзья** — список с аватарками, поиск и добавление по нику, меню друга (ЛС, удалить, игнорировать).
- **Пати** — приглашение, кик, роспуск и выход, подсказки ников (сначала друзья, потом игроки из Tab), принятие приглашений.
- **Мессенджер** — список чатов, переписка с датами, «Избранное» для заметок, закрепление, очистка и удаление чатов, игнор и приглашение в пати прямо из чата.
- **Выбор режима** — в меню паузы на `bloodstone.boo` и `extra.bloodstone.boo`: карточки режимов, поиск, избранное; кнопка сама проходит меню сервера и ставит в очередь или переносит.
- **Настройки** — готовые темы и своя тема, лимит хранения сообщений в ЛС.

Головы игроков и переписки сохраняются между сессиями.

## Дополнения

Другой мод может встроиться в окна BloodDesigner: свои пункты в меню друга, строка под ником, заявки в друзья,
проверка перед отправкой ЛС, карточки сообщений, кнопка у поля ввода и т. п. Всё лежит в `dev.no.name.blooddesigner.api`.

В `fabric.mod.json` дополнения:

```json
"entrypoints": {
  "blooddesigner": ["полное.имя.КлассаДополнения"]
}
```

Класс реализует `BloodDesignerAddon`; BloodDesigner вызывает `register(api)` один раз при запуске.
BloodDesigner от дополнений не зависит: без них всё работает как обычно, а дополнение без BloodDesigner просто не загружается.

## Сборка

Нужен JDK 25.

```
./gradlew build dist
```

Файлы всех версий окажутся в `dist/`. Общий код лежит в `src/main/java`, слой совместимости под каждую версию — в `versions/<версия>`.
