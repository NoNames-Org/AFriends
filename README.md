# AFriends

Клиентский мод для Fabric: друзья на любом сервере, мессенджер со сквозным шифрованием и API для аддонов.
Раньше назывался BloodDesigner: при первом запуске настройки, переписки и ключи сети переносятся сами.

## Возможности

- **Панель в чате** — справа ряд кнопок: друзья, сообщения, настройки и кнопки аддонов.
- **Друзья** — список с аватарками, поиск и добавление по нику, меню друга (ЛС, удалить, игнорировать).
- **Мессенджер** — личные и групповые чаты, голосовые, картинки и гифки, опросы, «Избранное», закрепление.
- **Сеть AFriends** — друзья и ЛС на любом сервере, сквозное шифрование, значок A у игроков с модом.
- **Настройки** — темы, история сообщений, сеть, звук и категории аддонов.

Меню батл пасса, магазина, пати и навигатор режимов для bloodstone.boo теперь в отдельном аддоне
[BloodDesignerAdvance](https://github.com/NoNames-Org/BloodDesignerAdvance).

## Аддоны

Аддон — отдельный Fabric-мод, который встраивается в окна AFriends через `dev.no.name.afriends.api`:
своя кнопка и панель у чата, пункты в меню друга и переписки, карточки сообщений, категория настроек и т. п.

```json
"entrypoints": { "afriends": ["полное.имя.КлассаАддона"] },
"depends": { "afriends": ">=2.0.0" }
```

Класс реализует `AFriendsAddon`; AFriends вызывает `register(api)` один раз при запуске. Подробнее —
[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). Пример аддона — BloodDesignerAdvance.

Чтобы собрать аддон против локальной версии AFriends: `./gradlew publishToMavenLocal --no-parallel`, в аддоне —
зависимость `dev.no.name:afriends:<версия>+<minecraft>` из `mavenLocal()`.

Нужны Fabric Loader 0.20.1+ и Fabric API. Готовые файлы — в [релизах](../../releases).

## Сборка

Нужен JDK 25.

```
./gradlew build dist
```

Файлы всех версий окажутся в `dist/`. Общий код лежит в `src/main/java`, слой совместимости под каждую версию — в `versions/<версия>`.
